01 Scaffold

Start from one of the maintained Starter Series templates.

02 Audit

Check release, CD, security, and agent-instruction hygiene.

03 Handoff

Generate a Launch Proof Report with evidence and blockers.

Audits stay narrow and inspectable.

The audit tools are read-only checks for launch hygiene. They avoid unsupported vendor claims and keep advisory instruction-risk reminders separate from hard duplicate or overlap findings.

audit_release

Version/tag drift, changelog drift, and publish workflow detection.

audit_cd

Public registry drift for supported destinations; unsupported destinations stay explicit.

audit_security

Core CI hardening checks such as gitleaks, CodeQL, audits, and least-privilege workflow habits.

audit_instructions

Exact duplicates, cross-file overlap, and keyword reminders for human review.

Launch Proof Reports are evidence, not certification.

The report combines release, CD, security, and instruction review into one handoff document. It exits non-zero when the repository is not actually launch-ready. 

# Launch Proof Report

release: ready
cd: review
security: hardened
instructions: attention

blockers:
- publish destination needs review
- instruction overlap needs owner decision

Use it as CLI, MCP server, plugin, or Desktop extension.

One binary switches between CLI and MCP stdio. The package also ships Claude Code plugin metadata, skills, and the release-built Desktop extension bundle.
